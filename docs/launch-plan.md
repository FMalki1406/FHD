# نطاق الإطلاق وخطة التحقق

التاريخ: 2026-09-21. الحالة: خطة لإطلاق تجاري متكامل؛ ليس MVP. بدأ تنفيذ قواعد المحرك الخالصة في Rust بجانب مختبر HTTP الداخلي؛ النقل الشبكي والتخزين والواجهة لم تنفذ. التقدم موثق في [سجل التنفيذ](execution-status.md).

## مراحل التنفيذ الداخلية

1. تعريف المنتج: جمهور وقيمة ومقارنة منافسين ومتطلبات مرقمة ومعايير قبول ومسارات استخدام.
2. إزالة المخاطر: مختبر أعطال للمحرك، وتجارب توافق المتصفح والواجهة على الأنظمة الثلاثة. هذه أدوات تحقق داخلية وليست إصدارًا تجاريًا مختصرًا.
3. بناء المنتج: المحرك والتخزين والتكامل والواجهة والقواعد والوسائط والخدمات التجارية وفق التبعيات.
4. التأهيل: اختبارات واقعية طويلة، مراجعات أمن وإتاحة وصول، وتجربة خاصة لاكتشاف العيوب قبل الإطلاق العام.
5. الإطلاق: حزم وتحديثات موقعة، إضافات معتمدة، شراء ودعم ووثائق ومراقبة تشغيل الخدمة.

لا توجد مدة أو ميزانية معتمدة. يُقدر الجدول بعد تحديد الفريق ومصفوفة الأنظمة ونتائج إثبات الجدوى.

## بوابات قبول تمنع الإطلاق عند الفشل

| المجال | الدليل المطلوب |
| --- | --- |
| سلامة الملفات | تطابق SHA-256 في جميع حالات المختبر المتوقعة؛ لا نجاح زائف ولا خلط لمورد تغير |
| التعافي | سيناريوهات قتل العملية وإعادة التشغيل وانقطاع الشبكة والنوم وامتلاء القرص وفصل القرص، مع توثيق مقدار العمل المعاد |
| المتصفح | نجاح حالات الدعم المحددة، وعدم فقد الطلب في الحالات غير المدعومة أو عند تعطل التطبيق |
| الأداء | قياس CPU والذاكرة والقرص والسرعة والبحث على أجهزة معلنة ومجموعة أحجام واتصالات؛ وضع حدود رقمية قبل التأهيل |
| المقارنة | نفس الملف والخادم والجهاز والشبكة وتكرارات متعددة؛ لا ادعاء «الأسرع» دون نتائج تدعمه |
| تجربة الاستخدام | إكمال التثبيت وربط الإضافة والتنزيل والاستعادة بلوحة المفاتيح، والتحقق من RTL وقارئ الشاشة |
| التحديث | رفض تحديث غير موثوق، وتعافٍ من تحديث منقطع، وتوافق تغييرات قاعدة البيانات ومسار رجوع مجرب |
| الترخيص | اختبارات انقطاع الخدمة والدفع المكرر واستعادة الشراء وفقد الجهاز؛ دون المساس بملفات المستخدم |
| الإصدار | لا عيوب حرجة مفتوحة تمس الملفات أو الأسرار أو التفعيل؛ لكل نظام أدلة اختبار خاصة به |

## مقاييس نجاح مقترحة

- نسبة إكمال المهام القابلة للتنزيل، مع فصل فشل التطبيق عن رفض الخادم.
- نسبة نجاح الاستعادة للحالات التي تسمح بالاستكمال؛ لا خلطها بالحالات غير المدعومة.
- الوقت من تثبيت التطبيق إلى أول تنزيل ناجح، ونسبة نجاح ربط الإضافة.
- الأعطال لكل ساعات تشغيل، والبايتات المعاد تنزيلها بعد التعطل.
- التحويل إلى شراء، والاستمرار في الاستخدام، وأسباب طلبات الدعم والاسترداد.

تُجمع مقاييس المنتج محليًا أو بموافقة مناسبة؛ لا تُرسل الروابط أو أسماء الملفات ضمن القياس. الأهداف العددية لم تعتمد بعد.
