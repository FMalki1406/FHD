# استقبال اقتراحات الواجهة والمتصفح

الحالة: `intake::Inbox` حد داخلي داخل العملية بين اقتراح غير موثوق وموافقة المتحكم المحلي. ليس إضافة متصفح ولا خادم IPC جاهزًا. الاقتراح يحمل رابط HTTPS ومعرف طلب محدودًا فقط؛ لا يحدد مسارًا أو cookies أو رؤوس اعتماد أو سماح HTTP أو تحويلات. اقتراح الرابط لا يجري DNS أو شبكة أو كتابة قرص ولا يلغي تنزيل المتصفح.

القائمة محدودة بـ64 اقتراحًا، تنتهي بعد 15 دقيقة؛ نفس معرف الطلب والرابط يرجع الاقتراح ذاته، وتغيير الرابط بالمعرف نفسه يرفض. بعد موافقة محلية صريحة على الرابط والوجهة والاسم، ينشئ المتحكم المهمة عبر المدير وينتظر إقرار القبول. المعاينة قد تتضمن رابطًا موقعًا حساسًا فلا تسجل أو تصدر تلقائيًا. آخر 256 معرفًا مقبولًا تمنع تكرارًا داخل عمر العملية، وليست سجل idempotency دائمًا.

نجاح enqueue لا يثبت المتانة إلا إذا استُخدم Manager::open الدائم. إلغاء انتظار approve بعد قبول المدير أو انهيار العملية قد يفقد سجل منع التكرار؛ لا تسلّم الإضافة التنزيل أو تلغيه اعتمادًا على هذه الطبقة وحدها. يلزم بروتوكول إقرار دائم بمعرف مصدر قبل ربط المتصفح الفعلي.

ما زال مطلوبًا: إضافة Chrome/Edge/Firefox وصلاحياتها، تسجيل native messaging وربط هوية المصدر، سياسات DNS/IP ومنع الوصول غير المصرح إلى الشبكات الخاصة، عزل أسرار الجلسات بحسب نطاقها ومسارها وعمرها، واختبار التسليم بعد التعطل. لا منفذ محلي يستمع في هذه الدفعة؛ typed API لا يجعل بيانات الصفحة موثوقة. لا توجد دعوى ربط المتصفح أو جاهزية الواجهة قبل تنفيذ واختبار هذه الأجزاء.
