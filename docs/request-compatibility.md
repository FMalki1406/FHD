# بيانات الطلب والتحويل بين المواقع

الحالة: واجهة محرك داخلية لمتصل محلي موثوق؛ نتائج الاختبارات تسجل في حالة التنفيذ. ليست واجهة متصفح منشورة.

## المنفذ

`Options.request_policy` يحدد Authorization وCookie اختياريين، وقائمة أصول مسموحة للتحويل. الإنشاء عبر `RequestPolicy::new` يتحقق من حجم كل رأس حتى 8192 بايت، ويرفض محارف التحكم وحقن CR/LF. لا توجد قائمة رؤوس حرة يمكنها تغيير Host أو Range أو Content-Length. تمثيل Debug منقح، ورؤوس reqwest موسومة حساسة. لا تطبع الأخطاء القيم الأصلية.

تُرسل بيانات الاعتماد فقط عندما يطابق أصل الطلب الأصل الأول: المخطط والمضيف والمنفذ الفعلي. عند الانتقال إلى CDN مصرح به لا تنتقل Authorization أو Cookie أو Referer. كل خطوة تحويل تخضع للتحقق؛ حد خمس تحويلات. التحويل إلى أصل مختلف يتطلب وجود الوجهة في القائمة الصريحة، بحد ثمانية أصول، دون مسارات أو query. الرجوع إلى الأصل الأول بعد أصل آخر يحتاج إدراجه أيضًا بالقائمة؛ هذه سياسة محافظة.

الانتقال من HTTPS إلى HTTP مرفوض دائمًا، حتى لو سُمحت طلبات HTTP صراحة. HTTP الأولي لا يسمح به إلا `allow_http` من المتصل الموثوق؛ السماح به يتضمن خطر إرسال بيانات الاعتماد دون TLS. لا ينبغي لواجهة الويب أو المتصفح منح هذا الإذن تلقائيًا.

سياسة الطلب نفسها تستخدم في الاستكمال والأجزاء المتوازية. لا يعطل السماح بالتحويل فحوص ETag والنطاق والطول وبصمة الوجهة النهائية. أي تغير في هوية الملف يبقى سبب رفض الاستكمال.

## نطاق Cookies وحدود التطبيق

الرأس الخام Cookie ليس مخزن Cookies للمتصفح: لا يطبق Path أو Secure أو SameSite أو انتهاء الصلاحية. يمتد الإذن داخل الأصل إلى جميع مساراته. البرنامج لا يجمع Cookies من المتصفح، ولا يستوعب Set-Cookie الوارد من الخادم، ولا يسجل جلسات الدخول تلقائيًا. على أي تكامل متصفح مستقبلي اختيار Cookies لكل رابط وسياق بشكل صحيح، وعدم تحويل صلاحية صفحة واحدة إلى إذن عام للأصل.

هذه واجهة لإرسال بيانات اعتماد قدمها المتصل الموثوق؛ لا تنفذ OAuth أو استيراد جلسة متصفح أو حل CAPTCHA أو تجديد تسجيل الدخول. حفظ الخيارات الحساسة في الطابور يستعمل تشفير الطابور المتاح على Windows، ولا يحول ذلك إلى ضمان سرية داخل ذاكرة عملية يسيطر عليها المستخدم.

## أدلة الاختبار المطلوبة

اختبارات HTTP محلية فعلية تغطي إرسال بيانات الاعتماد للأصل الأول، وبقاء البيانات مع تحويل من الأصل نفسه، وتجاهل Set-Cookie، وحذف البيانات عند تحويل مصرح لأصل آخر، ومنع الاتصال بوجهة غير مصرح بها. اختبارات السياسة تغطي حقن الرؤوس والحدود ورفض التخفيض من HTTPS والتنقيح. اختبار تخفيض HTTPS هنا اختبار سياسة؛ ليس حملة شهادات TLS كاملة.
