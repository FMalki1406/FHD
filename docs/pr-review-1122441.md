2. اختبار فشل حفظ الحالة بعد رفض الرابط، وفشل فك الختم بعد ذلك: نتيجة الخطأ، منع استعمال المقبض حين يتعذر تثبيت الحالة، والسلوك بعد إعادة الفتح. وجود التوكيدات للحالات المصطنعة لا يختبر هذه الفروع الحية.
3. تصحيح توصية عدد الروابط الصلبة في وثيقة العقد. العدد دليل عن الأسماء الحالية وليس تاريخ النشر أو شهادة سلامة السجل؛ لا يكشف كل استعادة لسجل قديم، ولا يضمن ثبات العدد بين الفحص والكتابة. لا يُعتمد nlink == 1 وحده إذنًا عامًا لفك الختم.
