## مطلوب قبل ربط المنسق

1. تعليق Publication المنقول إلى application/src/storage.rs:103–105 يعيد القول إن الإصدار لم يتغير وإن بايت الكاتب القديم يُقرأ Sealed قراءة محافظة. هذه العبارة هي عكس إصلاح v2؛ يجب حذفها واستبدالها بعقد صحيح.
2. تعليق publication() يقول حالة الجزء عند الفتح، والتنفيذ يرجع الحالة الحالية. وحالة الذاكرة بعد فشل المزامنة لا تثبت بايت القرص الحالي. عرّفها بوصفها آخر حالة اعتمدها هذا المقبض، مع قيود الفشل، ولا تعامل Open كإذن لتجاوز عمليات المنفذ أو حارس poisoned.
3. Integrity ليس تلف المحتوى فقط: الفتح يعيده أيضًا لطول أو هوية metadata غير صحيحين، أو اختلاف المهمة/الجيل/الحجم، أو بايت ختم غير قانوني. لا يسمح هذا وحده بفك الختم أو إعادة استعمال الكائن القديم. Superseded يشمل كل إصدار مختلف، حتى إصدارًا أحدث، لا القديم وحده.
4. ReplaceRepresentation يرفع الجيل ويمسح خريطة المقاطع، لكنه ليس وحده إجراء تعافٍ كاملًا. يجب حفظ انتقال الجيل، وإنشاء الجزء الجديد حصريًا، وعدم تعديل الجزء القديم، وعدم استبدال وجهة موجودة؛ واختبار التعطل حول حفظ الانتقال وإنشاء الجزء. حالة Linked تحتاج مصالحة نتيجة النشر لا إعادة تنزيل تلقائية لمجرد غياب مسار الوجهة.
