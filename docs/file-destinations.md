# الوجهات وتعارض الأسماء والمساحة

الحالة: واجهة داخلية `files::export_completed` لتصدير ملف مكتمل إلى مجلد يختاره المتصل المحلي الموثوق. تفتح مخزن المصدر تحت قفله وتتحقق من حالته وبصمته، ثم تنسخ بقطع 64KiB إلى ملف مؤقت في الوجهة وتطابق SHA-256 والحجم قبل النشر الحصري. يدعم ذلك وجهة على قرص مختلف مع الاحتفاظ بالأصل للاستعادة.

سياسات التعارض: Reject يرجع تعارضًا، Skip يترك الملف الموجود دون ادعاء أنه مطابق، Rename يبحث حتى ألف لاحقة دون استبدال. الاسم محدود ويُرفض traversal وأسماء Windows المحجوزة والـalternate streams. تُرفض الروابط المعروفة في سلسلة الوجهة. المجلدات يجب أن تكون خاصة وموثوقة؛ لا حماية شاملة من تبديل المسارات بواسطة برنامج بصلاحيات المستخدم نفسه.

`check_space` يسأل النظام عن المساحة المتاحة للمتصل ويرفض عجز المساحة أو overflow. التصدير يترك احتياطًا مقداره 1MiB؛ الفحص استرشادي وليس حجزًا، والكتابة قد تفشل إذا تغيرت المساحة أو الحصة. استدعاءات Windows وUnix معزولة في platform-files، دون unsafe داخل المحرك.

تنظف الدالة ملفها المؤقت عند الخروج العادي أو الفشل. لا تُحذف ملفات جزئية أو مجهولة آليًا. انهيار العملية قد يترك مؤقتًا يحتاج إجراء تنظيف موثوقًا لاحقًا؛ لا مسح شامل للمجلد. `Manager::forget` يحذف بيانات المهمة غير الجارية من القائمة فقط، ويحتفظ بالملفات؛ المعرّفات لا يعاد استخدامها بعد الحذف وإعادة الفتح. إعادة البدء تستخدم مهمة جديدة ومجلدًا جديدًا مع إبقاء القديمة.

على Unix تزامن الوجهة بعد النشر؛ Windows لا يضمن مزامنة الدليل أو متانة فصل الكهرباء. التصدير عملية blocking غير قابلة للإلغاء حاليًا ويجب تشغيلها على عامل مخصص؛ لا يُدعى اكتمال واجهة نقل/تنظيف الملفات أو دعم الاستبدال الصريح بهذه الدفعة.

قبل نقل ملف معروف الحجم تُفحص المساحة المتبقية المطلوبة؛ للاستجابة مجهولة الحجم يفحص حد احتياط أولي فقط ويظل سقف البايتات وأخطاء الكتابة مصدر الحماية أثناء النقل. الفحص لا ينفذ تخصيصًا مسبقًا أو حجزًا ولا يضمن استمرار توافر المساحة.
