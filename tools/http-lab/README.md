# مختبر أعطال HTTP

أداة هندسية داخلية تختبر سيناريوهات سنستخدمها للتحقق من محرك التنزيل. ليست تطبيق التنزيل ولا خدمة منتج. تعمل دون تبعيات npm خارجية ولا تصل إلى الإنترنت أو ملفات المستخدم.

## التشغيل

يتطلب Node.js 22 أو أحدث. من جذر المشروع:

```sh
npm test
npm run lab:serve
```

على PowerShell يمكن استخدام `npm.cmd` إذا حجبت سياسة الجهاز `npm.ps1`. الخادم يستمع على `127.0.0.1` ومنفذ عشوائي يطبعه عند البدء. يمكن تحديد المنفذ بمتغير `FHD_LAB_PORT`. أوقفه بـCtrl+C. لا يُشغّل تلقائيًا عند تسجيل الدخول.

## السيناريوهات

| المسار | السلوك |
| --- | --- |
| `/file` | 64 KiB ثابتة، ETag قوي، GET وHEAD وRange مفرد وIf-Range |
| `/no-range` | يتجاهل Range ويرجع كامل الملف |
| `/drop` | يقطع الاتصال بعد جزء من البيانات |
| `/short-body` | ينهي استجابة أقصر من Content-Length المعلن |
| `/wrong-range` | يعطي Content-Range خاطئًا عمدًا عند طلب نطاق |
| `/slow` | دفعات صغيرة متأخرة |
| `/redirect` | تحويل نسبي إلى الملف |
| `/loop` | تحويل دائري لاختبار حدود التتبع |
| `/status/{code}` | 403 و404 و429 و500 و502 و503؛ Retry-After لبعض الأخطاء المؤقتة |

للتغيير بين نسختين بنفس الحجم، يستدعي الاختبار `lab.changeVersion()` عبر واجهة البرمجة المحلية؛ لا توجد نقطة HTTP لتغيير الحالة. كل مختبر اختبار معزول بمنفذ مستقل، ويلتقط الطلب نسخة ثابتة من المورد.

## حدود الدليل

الاختبارات تتحقق من صحة الخادم التجريبي وإعادة تركيب نطاقاته في الذاكرة، وليس من متانة محرك Rust أو SQLite أو القرص. لا يدعم المختبر بعد TLS أو HTTP/2 أو HTTP/3 أو ملفات ضخمة أو محاكاة عطب القرص. يرفض النطاقات المتعددة والمشوهة بـ416 كسياسة اختبار مبسطة، ولا يدعي تنفيذ كل دلالات HTTP.

يرفض Origin وHost غير المتوقع ولا يوفر CORS؛ مخصص لعملاء الاختبار المحليين. لا يُعرض على الشبكة العامة.
